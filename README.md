# AI Video Studio

대본이나 내 사진만 넣으면 **내 캐릭터가 설명하는 유튜브 영상**(자연스러운 TTS 내레이션, 한/영 자막, 썸네일, SRT)을 자동으로 만들어 주는 웹 앱입니다. Google Gemini API를 사용합니다.

👉 **바로 사용하기: https://yuna123-tech.github.io/ai-video-studio/**

## 사용 방법 (웹사이트)
1. 위 주소를 크롬(또는 엣지)으로 엽니다.
2. 왼쪽 맨 위 **"API 키 · 사용량 · 한도"**를 열고 내 Gemini API 키를 넣습니다. (키 발급: https://aistudio.google.com/apikey)
3. 대본을 쓰거나 사진을 올리고 **영상 생성하기**를 누릅니다.

- 사이트에는 API 키가 들어 있지 않습니다. 각자 입력한 키는 **그 사람의 브라우저에만** 저장되고, 사용량도 그 키로 계산됩니다.
- 요금이 나가지 않게 하려면 **결제(billing)를 연결하지 않은 무료 프로젝트의 키**를 쓰세요. 앱 안의 하루 한도·절약 모드도 함께 쓰면 좋습니다.

## 내 컴퓨터에서 실행
1. [Node.js](https://nodejs.org) (LTS) 설치
2. `npm install`
3. (선택) `.env.local` 파일에 `GEMINI_API_KEY=내키` — 개발 서버에서만 쓰이고 배포 빌드에는 절대 들어가지 않습니다.
4. `npm run dev` → http://localhost:3000

## 배포
`main` 브랜치에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 빌드해서 GitHub Pages에 자동 배포합니다.

## v2 변경 사항 (자연스러운 TTS · 편의 기능)

### TTS 품질
- **말투/연출 프리셋**: 자연스러운 내레이션, 정보 전달, 스토리텔링, 다큐, 쇼츠, 뉴스, 직접 입력. Gemini TTS의 자연어 연출 지시를 사용합니다.
- **말하기 속도 / 장면 사이 숨 고르기** 설정
- **읽기용 텍스트(ttsText)**: 대본 분석 시 자막용 문장과 별도로 "읽는 그대로" 버전을 함께 생성합니다 (3가지 → 세 가지, AI → 에이아이). 장면별로 직접 수정할 수 있고 자막에는 표시되지 않습니다.
- **발음 사전**: `단어=읽는 법` 형식으로 등록하면 모든 장면에 적용됩니다.
- **오디오 후처리** (`services/audioUtils.ts`): 앞뒤 무음 제거, 음량 평준화, 클릭 방지 페이드, 일정한 장면 간 쉼
- 목소리 16종 (성별 필터, 현재 말투로 미리듣기), Flash/Pro TTS 모델 선택 (Pro 실패 시 Flash로 자동 전환)

### 편의 기능
- 장면별 **음성 다시 만들기 / 이미지 다시 만들기 / 음성 듣기**
- 대본 수정 시 "음성 갱신 필요" 표시 + 수정된 장면만 일괄 재녹음, 전체 재녹음
- **배경음악(BGM)** 업로드, 볼륨 조절, 시작/끝 페이드
- 이미지 생성과 음성 합성을 병렬로 처리해 생성 시간 단축

### 렌더링 / 자막
- 오디오 시계 기준으로 렌더링해 영상과 소리가 어긋나지 않음
- 이미지에 Ken Burns(줌/팬) 효과 + 장면 전환 크로스페이드
- 자막을 문장·쉼표 단위로 나누고 실제 발화 시간에 맞춰 표시 (미리보기 · 영상 · SRT 동일)
- 한글 SRT 추가, 영어 자막은 한국어 문장 단위로 정렬
- 버그 수정: 괄호 제거 정규식이 `A(1) B (2) C` → `A C`처럼 사이 문장까지 지우던 문제

## v3 변경 사항 (썸네일 자동 제작 · 내 사진 편집)

### 썸네일 자동 제작 (`components/ThumbnailStudio.tsx`, `services/thumbnailService.ts`)
- AI가 제목과 별도로 **썸네일 전용 후킹 문구**(2줄)를 만들고, 첨부 사진 중 썸네일에 가장 좋은 사진을 골라 자동 합성합니다.
- 배경 선택: AI 생성 배경 / 장면 이미지 / 내 사진. **선택한 사진 AI 보정**: 인물·대상은 그대로 두고 색감·조명·구도만 썸네일용으로 다듬습니다.
- 레이아웃 3종(굵은 외곽선, 색 띠 강조, 중앙 깔끔) + 강조 색상, 문구 직접 수정. 미리보기가 저장 결과와 동일합니다 (JPG, 유튜브 권장 크기).

### 내 사진 활용 (`components/PhotoManager.tsx`, `services/imageUtils.ts`)
- **대본 모드 + 내 사진**: "내 사진 함께 쓰기"에 사진을 넣으면 AI가 대본 내용과 맞는 장면에 사진을 배치하고, 나머지 장면만 AI 이미지로 만듭니다.
- **내 사진으로만 편집**: 주제/메모를 쓰면 사진을 보고 대본을 작성하고, 완성 대본을 붙여넣으면 문장마다 맞는 사진을 배치합니다. "AI가 이야기 순서로 배치" 또는 "내가 정한 순서대로"를 선택할 수 있습니다.
- 드래그로 사진 순서 변경, 끌어다 놓기 업로드, 장면별 사진 교체(썸네일 클릭), 장면에 새 사진 바로 추가
- 큰 사진은 자동으로 줄여 저장하고, AI 분석에는 작은 사본만 보내 속도와 비용을 줄입니다.
- 사진 속 주인공 위치(focus)를 AI가 찾아 그 부분이 잘리지 않게 자르고, 비율이 크게 다른 사진(예: 가로 사진을 쇼츠에)은 흐린 배경을 깔고 사진 전체를 보여줍니다.

## v4 변경 사항 (캐릭터 진행자 · API 키/사용량)

### 내 캐릭터가 설명하는 영상 (`components/PresenterPanel.tsx`, `services/presenterService.ts`)
- **캐릭터가 진행 (기본값)**: 설정한 캐릭터가 모든 장면 구석(왼쪽/오른쪽)에 서서 설명합니다. 대본·AI 이미지·내 사진·Veo 영상 어떤 장면이든 빠지지 않습니다.
- 캐릭터는 스타일 + "캐릭터 고정 설명"으로 **한 번만 그려서 저장**하고 계속 재사용합니다 (설명을 바꾸면 다음 생성 때 새로 그림). 내 캐릭터 이미지(투명 PNG 권장)를 올려도 됩니다.
- 초록 배경으로 그린 뒤 배경을 자동으로 지워 캐릭터만 남깁니다. 배경을 못 지우면 흰 테두리 카드로 표시합니다.
- 대본은 **캐릭터가 시청자에게 직접 설명하는 말투**로 작성되고, 장면마다 포즈(설명/가리키기/놀람/기쁨)를 골라 같은 캐릭터로 포즈 이미지를 만듭니다. 장면 카드에서 포즈를 바꿀 수 있습니다.
- 내보낸 영상에서는 캐릭터가 **내레이션 음량에 맞춰 들썩이며 말하는 듯** 움직이고, 자막은 캐릭터를 피해서 배치됩니다.
- **장면 속 등장** 모드: AI 그림 안에 캐릭터를 그리되, 저장된 캐릭터 이미지를 참고 이미지로 넘겨 모든 장면에서 같은 얼굴·옷을 유지합니다.

### API 키 · 사용량 (`components/ApiUsagePanel.tsx`)
- 이 프로그램이 어떤 Google API 키를 쓰는지 표시하고, 직접 키를 입력할 수 있습니다 (브라우저에만 저장).
- 이번 세션의 대본 분석/이미지/음성/Veo 호출 수와 토큰 수를 보여줍니다.

## v5 변경 사항 (요금 방지 · 토큰 절약)

`services/budgetService.ts`, 사이드바 맨 위 "API 키 · 사용량 · 한도"

- **하루 호출 한도**: 대본·분석 / 이미지 / 음성 / Veo 별로 하루 최대 호출 수를 정하면, 넘기 직전에 호출하지 않고 멈춥니다. (기본: 50 / 40 / 80 / 0, 날짜가 바뀌면 초기화)
- **Google 한도 소진 감지**: Google이 일일·무료 한도 소진이나 지출 한도 도달을 알려오면 재시도·다른 모델 시도 없이 즉시 멈추고, 그날은 그 기능을 더 호출하지 않습니다. 분당 제한(잠깐 기다리면 풀리는 429)만 재시도합니다.
- **생성 전 확인**: 대본 분석 후 필요한 이미지·음성 수를 계산해 남은 한도보다 많으면 먼저 물어봅니다.
- **이어서 만들기**: 한도 때문에 멈추면 만든 장면은 그대로 두고, "빈 장면 채우기"로 빠진 이미지·음성만 나중에 만들 수 있습니다 (대본 재분석 없음).
- **절약 모드 (기본 켜짐)**: Veo 끄기, 음성 Flash 모델 고정, 썸네일 AI 배경은 버튼을 누를 때만, 캐릭터 포즈는 기본 1장, 같은 대본+설정은 이전 분석 재사용.
- **중복 호출 방지**: 같은 문장·같은 목소리 설정의 음성(미리듣기 포함)은 다시 만들지 않고 저장된 것을 씁니다.

> 이 프로그램의 한도는 이 브라우저 안에서만 지켜지는 보조 장치입니다. 요금이 절대 나가지 않게 하는 가장 확실한 방법은 **결제(billing)를 연결하지 않은 무료 프로젝트의 API 키**를 쓰는 것입니다.
